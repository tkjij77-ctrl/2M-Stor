  النسخة السحابية (Supabase + وضع محلي احتياطي)
═══════════════════════════════════════════════════════════

● التشغيل السريع:
  افتح index.html في المتصفح — بيشتغل فوراً بدون أي إعداد
  (في الوضع المحلي بحسابات: admin/admin و Amel/Amel)

● التفعيل السحابي (مرة واحدة — 5 دقايق):
  1) في Supabase: SQL Editor ← شغل ملف cloud-schema.sql
  2) Authentication ← Providers ← Email ← عطّل "Confirm email"
  3) في التطبيق: القائمة ← ⚙️ الإعدادات (كمدبر) ← ☁️ الاتصال السحابي
     ← حط الـ URL + الـ anon key ← 🧪 اختبار ← 💾 حفظ وتفعيل
  4) أول تسجيل إيميل في التطبيق = مدير تلقائياً
     وبعدها تعمل حسابات للعمال من "إدارة الحسابات"

● المميزات السحابية:
  • أجهزة غير محدودة + متابعة المبيعات من موبايلك
  • مزامنة تلقائية (دفع خلال ثواني + سحب كل 30 ثانية)
  • أوفلاين: الكاونتر ما بيوقفش، والتغييرات تترحل بعد النت
  • نسخ احتياطي حقيقي (قاعدة بيانات سحابية)
  • أول بياناتك (227 صنف + الفواتير) بتتترحّل تلقائياً

● لو حصلت أي مشكلة:
  الإعدادات ← ☁️ الاتصال السحابي ← ⏹ إيقاف (تعود للتخزين المحلي)

● الملفات:
  index.html      — التطبيق كله
  manifest.json   — تعريف التطبيق (PWA)
  sw.js           — Service Worker (أوفلاين + تحديثات)
  icon-192/512    — أيقونات التثبيت
  cloud-schema.sql— مخطط قاعدة البيانات السحابية
  دليل-التشغيل-السحابي.md — الشرح الكامل
